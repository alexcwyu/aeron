# Sleeping idle strategy init args: no state leak on invalid durations

Cherry-picked onto 1.53.3 as `bfd722e44f` (2026-09-26), from `c456fa85c7` on
`patch/1.52.2-consolidated`. The four fixes of that tag carry no per-fix patch
entry; this entry records the fix, its regression test, and its evidence.

## Bug and correction

Upstream `aeron_idle_strategy_sleeping_init_args`
([aeron_agent.c](../../aeron-client/src/main/c/aeron_agent.c)) allocated the
strategy's state buffer first and then parsed `init_args` directly into it,
returning the parse result. An unparseable duration (for example `abc`) left
the state allocated while returning `-1`; `aeron_idle_strategy_load`'s
caller-side state pointer is local and discarded on a negative init return, so
that allocation leaked on every invalid `sleeping`/`sleep-ns` idle strategy
configuration string.

The fix parses into a stack-local `duration_ns` first and allocates only once
parsing succeeds, so a failed parse allocates nothing. It also narrows the
"Failed to allocate sleeping state" error message to the actual
allocation-failure branch. No ABI, layout, or hot-path change: the idle
function and its state layout are untouched.

## Regression and evidence

[IdleStrategyTest.shouldRejectInvalidSleepingInitArgsWithoutAllocatingState](../../aeron-client/src/test/c/aeron_agent_test.cpp)
calls the init function with an invalid duration and asserts both `-1` and
that a NULL `state` stays NULL — with the pre-fix source the allocation happens
before the parse and is written into `*state`, so the test observes a non-NULL
pointer and fails. The two companion cases pin the success paths: a parsed
duration (`250us` becomes 250000 ns) and the default (one nanosecond when
`init_args` is NULL), each freeing the state through `aeron_free`.

A sanitizer build (ASan+UBSan+LeakSanitizer) turns any regression into a leak
report even if the pointer assertion were removed. The test is a unit test of
the init function: no driver, no JVM, no threading.

## Reproduce

```sh
cmake -S . -B build-c-tests -DCMAKE_BUILD_TYPE=Debug -DAERON_TESTS=ON \
  -DAERON_UNIT_TESTS=ON -DAERON_SYSTEM_TESTS=OFF -DAERON_BUILD_SAMPLES=OFF \
  -DBUILD_AERON_ARCHIVE_API=OFF -DSANITISE_BUILD=ON
cmake --build build-c-tests --target agent_test
LD_LIBRARY_PATH=$PWD/build-c-tests/lib ctest --test-dir build-c-tests \
  -R '^agent_test$' --output-on-failure
```

Negative control: restore the upstream function body (allocate first, parse
into `*state` last) and rerun; the invalid-args case fails on the non-NULL
`state`, and LeakSanitizer reports the leaked allocation on exit.

Configuration requires JDK 17+ at CMake configure time; no runtime JVM.
